# W33D Moderation Tracker — Windows downloads

This repository holds public EXE releases. The development source is maintained separately.

## Download and run

Open [Releases](https://github.com/ThePotato6801/W33D-Tracker-Releases/releases) and download the `Windows_x64.zip` asset. Extract the entire ZIP, then run **W33D_Tracker.exe**. Keep its **Program Files** folder beside it. No separate Python installation is required.

GitHub's automatic **Source code** ZIP is not the application.

## Updates

In v1.9.9 and newer, click **Check for updates**, review the version, then choose **Download and restart**. Close the separate staff sign-in window first. Downloads and installation require your confirmation. Saved history, preferences and staff sessions remain on your PC.

## Publishing status

The public release channel is active. [Download the latest Windows application](https://github.com/ThePotato6801/W33D-Tracker-Releases/releases/latest).

No GitHub account, access token, Python installation, or build script is needed to use the application or download updates. The publishing credential stays in the private source repository's GitHub Actions secrets and is not included in the app.

Only application downloads belong here. Do not upload local history databases, login sessions, browser profiles or credentials.
